# Google Play 내부 테스트 등록 가이드

목표: Play Console **내부 테스트**로 앱을 올려서, 휴대폰 Play 스토어에서 워치에 설치·업데이트.

> Play Console 화면 구성과 메뉴 이름은 자주 바뀌므로 아래 경로가 실제와 조금 다를 수 있음.
> **(불확실)** 표시는 확인하지 못한 부분.

## 준비된 파일

| 파일 | 용도 |
|---|---|
| `app-release.aab` | Play 에 올리는 앱 번들 (업로드 키로 서명, targetSdk 35) |
| `icon-512.png` | 스토어 아이콘 512×512 |
| `feature-1024x500.png` | 그래픽 이미지 1024×500 |
| `privacy-policy.html` | 개인정보처리방침 (웹에 올려서 URL 필요, `[개발자 이메일 주소]` 채우기) |
| `upload-keystore.jks` + `keystore.properties` | **업로드 키. 절대 공유·분실 금지, 반드시 백업** |

## 0. 시작 전 주의

- **기존에 PC로 설치한 앱은 삭제해야 함.** 서명 키가 달라서 Play 버전으로 덮어쓰기가 안 됨 (설정값도 초기화됨).
- **패키지 이름 `com.resttimer.wear` 는 한 번 올리면 영구히 바꿀 수 없음.** 이미 다른 사람이 쓰고 있으면 업로드 시 오류가 나며, 그때는 이름을 바꿔 다시 빌드해야 함.
- 업로드 키를 잃어버리면 Play 고객지원을 통해 재설정해야 함 (Play 앱 서명 사용 시).

## 1. 개발자 계정

1. https://play.google.com/console 에서 가입 (등록비 25달러, 본인 인증)
2. 계정 유형: 개인 / 조직. 개인 계정은 나중에 **정식 출시** 전에 "테스터 12명 × 14일" 비공개 테스트가 필요 (내부 테스트에는 해당 없음)

## 2. 앱 만들기

**모든 앱 → 앱 만들기**
- 앱 이름: `휴식 타이머`
- 기본 언어: 한국어
- 앱 / 게임: 앱
- 무료 / 유료: 무료 (나중에 유료로 바꿀 수 없음)

## 3. Wear OS 폼 팩터 추가

**테스트 및 출시 → 설정 → 고급 설정 → 폼 팩터** 에서 **Wear OS** 추가.
워치 전용 앱이라 "Wear OS 전용" 트랙을 쓰라고 안내할 수 있음 — 안내에 따름 **(불확실)**.

## 4. 앱 콘텐츠 (정책 신고)

**모니터링 및 개선 → 정책 및 프로그램 → 앱 콘텐츠** 의 항목 모두 작성.

| 항목 | 답변 |
|---|---|
| 개인정보처리방침 | 웹에 올린 `privacy-policy.html` 의 URL |
| 광고 | 광고 없음 |
| 앱 액세스 권한 | 모든 기능 제한 없이 이용 가능 |
| 콘텐츠 등급 | 설문 작성 (폭력·성적 콘텐츠 등 모두 "아니요", 유틸리티 카테고리) |
| 타겟층 | 13세 이상 등 (아동 대상 아님) |
| 데이터 보안 | **데이터 수집 안 함, 공유 안 함** |
| 건강 앱 | 해당 카테고리 없음 / 건강 데이터 사용 안 함 **(불확실: 운동 관련이라 질문이 나올 수 있음)** |
| 정부·금융 앱 | 해당 없음 |
| **정확한 알람** (`USE_EXACT_ALARM`) | 핵심 기능: **알람/타이머**. 설명 예: "운동 세트 사이 휴식시간이 끝나는 정확한 시각에 진동·소리로 알려야 함" |
| **전체 화면 알림** (`USE_FULL_SCREEN_INTENT`) | 알람 기능에 해당한다고 신고. 거절되면 사용자 동의로 대체 (앱 설정에 "전체 화면 알림 허용" 항목이 나타남) |
| 포그라운드 서비스 | `shortService` 사용 (3분 이내 알림). 신고 항목이 나오면: "휴식 종료 시 사용자가 끌 때까지 최대 30초간 진동·비프음" **(불확실: shortService 가 신고 대상인지)** |

## 5. 스토어 등록정보

**성장 → 스토어 등록정보 → 기본 스토어 등록정보**

- 앱 이름: `휴식 타이머`
- 간단한 설명 (80자):
  `하단 버튼 한 번으로 세트 간 휴식시간을 재는 갤럭시워치·Wear OS 타이머`
- 자세한 설명:
  ```
  웨이트 트레이닝 세트 사이 휴식시간을 워치 하단 버튼 한 번으로 재는 Wear OS 전용 타이머입니다.

  • 하단 버튼 한 번으로 휴식 타이머 시작
  • 0초가 되면 진동과 소리로 알림, 하단 버튼으로 바로 해제
  • 휴식시간 10초 단위 조정 (기본 1분 30초), 베젤 회전 지원
  • 진동·소리 각각 켜고 끄기
  • 운동 모드: 세트 중 화면이 꺼져도 다시 켜면 앱으로 복귀
  • 개인정보 수집 없음, 인터넷 사용 없음

  ※ Wear OS 3 이상 워치 전용 앱입니다 (갤럭시워치4 이후 등).
  ```
- 앱 아이콘: `icon-512.png`
- 그래픽 이미지: `feature-1024x500.png`
- 스크린샷: **Wear OS 스크린샷 최소 1장 (1:1 비율, 기기 테두리 없이)**. 휴대폰 스크린샷을 요구하면 같은 이미지를 쓸 수 있는지 확인 **(불확실)**
- 카테고리: 건강/운동

### 워치 스크린샷 찍기 (PC, adb 연결 상태)
PowerShell 에서 `>` 로 저장하면 이미지가 깨지므로 아래처럼 워치에 저장 후 가져옴:
```
.\adb -s <워치IP:포트> shell screencap -p /sdcard/shot1.png
.\adb -s <워치IP:포트> pull /sdcard/shot1.png
```
대기 화면, 카운트다운, 휴식 끝, 설정 화면 4장 정도 권장.

## 6. 내부 테스트 출시

1. **테스트 및 출시 → 테스트 → 내부 테스트 → 테스터** 탭: 이메일 목록 만들기 → 본인 Google 계정(워치에 로그인된 계정) 추가
2. **출시** 탭 → 새 버전 만들기
   - Play 앱 서명: **Google 에서 생성한 키 사용** (기본값) 선택
   - `app-release.aab` 업로드
   - 출시 노트: `첫 내부 테스트 버전`
3. 검토 → 출시 시작
4. **테스터** 탭의 **참여 링크** 복사 → 휴대폰에서 열기 → "테스터 되기"
5. 휴대폰 Play 스토어에서 휴식 타이머 → 설치 대상에서 **워치** 선택 (또는 워치의 Play 스토어에서 검색)
   - 처음 등록 후 스토어에 보이기까지 몇 시간 걸릴 수 있음

## 7. 업데이트할 때

`versionCode` 를 올려서 다시 빌드 → 내부 테스트에 새 버전 업로드 → 워치에 자동 업데이트.
