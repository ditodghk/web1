# 휴식 타이머 (갤럭시워치6 / Wear OS)

웨이트 트레이닝 세트 사이 휴식시간을 **워치 하단 버튼 한 번**으로 재는 앱.

## 사용법

| 화면 | 하단 버튼 | 화면 터치 |
|---|---|---|
| ① 대기 | 타이머 시작 | `−`/`+` 또는 베젤 회전으로 10초 단위 조정, ⚙ 설정 |
| ② 카운트다운 | 설정에 따라 **처음부터 다시**(기본) 또는 **무시** | 길게 누르면 취소 |
| ③ 휴식 끝 | 알림 끄고 ①로 (= [다시]) | [다시] 버튼 |
| 설정 | 설정 닫기 | 진동 / 소리 / 카운트다운 중 버튼 동작 |

- 기본 휴식시간 1:30, 범위 0:10 ~ 10:00
- 알림 기본값: 진동 + 소리 (설정에서 각각 끄기 가능)
- 진동·소리는 30초 후 자동으로 멈추고, 화면은 [다시]를 누를 때까지 유지
- 화면이 어두운/꺼진 상태에서는 첫 버튼은 화면만 깨우고, 한 번 더 눌러야 동작
- 하단 버튼이 타이머 조작에 쓰이므로 **앱을 나갈 때는 상단(홈) 버튼**을 사용
- **운동 모드**: 타이머를 한 번 시작하면 켜짐. 대기 화면에서도 진행 중 활동을 유지해서,
  세트 중 화면이 꺼졌다 켜져도 워치페이스가 아니라 앱으로 돌아옴.
  대기 상태로 **10분** 지나면 자동 종료, 또는 대기 화면의 **[운동 종료]** (앱도 닫힘)

## 설치 (PC → 워치, ADB 무선 디버깅)

1. 워치: 설정 → 시계 정보 → 소프트웨어 정보 → **소프트웨어 버전**을 여러 번 탭 → 개발자 모드 켜짐
2. 워치: 설정 → 개발자 옵션 → **ADB 디버깅** 켜기, **무선 디버깅** 켜기
3. 무선 디버깅 → **새 기기 페어링** → 표시되는 IP:포트와 페어링 코드 확인
4. PC (워치와 같은 Wi-Fi, [Android platform-tools](https://developer.android.com/tools/releases/platform-tools) 설치):
   ```
   adb pair <IP>:<페어링 포트>      # 페어링 코드 입력
   adb connect <IP>:<무선 디버깅 화면의 포트>
   adb install -r app-release.apk
   ```
5. 처음 실행 시 **알림 허용**을 눌러야 진행 상태와 휴식 종료 화면이 정상 표시됨

## 빌드

```
./gradlew assembleRelease     # app/build/outputs/apk/release/app-release.apk
./gradlew testDebugUnitTest   # 로직 단위 테스트
```
`./gradlew bundleRelease` 는 Play 업로드용 AAB (`app/build/outputs/bundle/release/app-release.aab`).
`keystore.properties` + 업로드 키가 있으면 그 키로, 없으면 debug 키로 서명함 (`app/build.gradle.kts`).
키 파일은 git 에 올리지 않음. Play 등록 절차는 [`store/PLAY_RELEASE.md`](store/PLAY_RELEASE.md).

## 구조

| 파일 | 역할 |
|---|---|
| `TimerLogic.kt` | 순수 로직 (버튼 동작 결정, 시간 조정/표시) — 단위 테스트 대상 |
| `TimerController.kt` | 상태·설정 관리, 저장/복원, AlarmManager 예약 |
| `MainActivity.kt` | 하단 버튼 가로채기, 앰비언트(어두운 화면) 처리 |
| `RestTimerApp.kt` | Compose UI (대기/카운트다운/알림/설정) |
| `AlarmReceiver.kt` | 0초 시점 알람 수신 |
| `AlertService.kt` | 진동·비프음 (포그라운드 서비스) |
| `Notifications.kt` | 진행 중 알림 + Ongoing Activity, 전체 화면 알림 |

## 실기기에서 확인이 필요한 항목

에뮬레이터/실기기 테스트를 하지 못했으므로 아래는 **확인되지 않음**:

- [ ] 하단 버튼이 앱으로 전달되는지 (뒤로 가기 키로 들어온다고 가정). 워치 설정의 버튼 사용자 지정에 따라 달라질 수 있음
- [ ] 화면이 꺼진 상태에서 첫 버튼이 무시되고 두 번째에 동작하는지
- [ ] 화면이 꺼진 동안 0초가 되면 알림 화면이 자동으로 뜨는지 (전체 화면 인텐트)
- [ ] 소리 크기 (알람 음량 사용), 무음 모드일 때 소리가 나는지
- [ ] 운동 모드 대기 화면에서 화면이 꺼졌다 켜질 때 워치페이스가 아니라 앱으로 돌아오는지
